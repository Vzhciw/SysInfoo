sysinfo.sh
Bash-скрипт для быстрого сбора базовой информации о состоянии Linux-хоста: пользователи, процессы, сетевая активность.
Зачем это нужно
Один из первых шагов при реагировании на инцидент (incident response) или при построении baseline системы - быстро понять "что вообще происходит на хосте": кто в системе, какие процессы запущены, какие порты слушаются, куда идут сетевые соединения. Обычно это делается вручную набором отдельных команд - скрипт автоматизирует и структурирует этот процесс в единый отчёт.
Что делает скрипт
Скрипт разбит на три блока:
1. Пользователи
whoami - под кем запущен скрипт who - кто сейчас залогинен в системе last -n 10 — история последних 10 входов (полезно для выявления подозрительных/нетипичных входов) /etc/passwd — список всех пользовательских аккаунтов системы
1. Процессы
ps aux --sort=-%cpu — топ-10 процессов по потреблению CPU ps aux --sort=-%mem — топ-10 процессов по потреблению памяти
1. Сеть
ss -tulpn — все слушающие TCP/UDP порты с привязкой к процессам ip a — сетевые интерфейсы и IP-адреса ss -tp — активные установленные соединения (кто с кем сейчас связан) Использование bash chmod +x sysinfo.sh ./sysinfo.sh
Сохранить результат в файл-отчёт:
bash ./sysinfo.sh > report_$(date +%F).txt Требования
Стандартные утилиты Linux: bash, ps, ss, ip, who, last. Присутствуют по умолчанию в большинстве дистрибутивов (тестировалось на Kali Linux).
Возможные доработки Экспорт в JSON для последующей отправки в SIEM Добавление проверки контрольных сумм критичных бинарников Флаги для выбора конкретных блоков (--users, --net, --proc)
